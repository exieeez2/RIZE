# Security Policy

## Reporting Security Vulnerabilities

We take security seriously. If you discover a vulnerability or security issue within RIZE, please do **NOT** open a public issue.

Instead, please report the vulnerability privately by:
- Creating a confidential issue on GitLab (check the "This issue is confidential" checkbox when creating an issue).
- Contacting the maintainers directly through private channels.

Please provide:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and suggested mitigations if available.

We will review your report and respond as promptly as possible.
